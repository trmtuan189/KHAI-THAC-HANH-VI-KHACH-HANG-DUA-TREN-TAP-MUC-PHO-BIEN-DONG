Mining Top-K Sequential Patterns with Leverage Using the SKOPUS Algorithm (SPMF documentation)

This example explains how to run the SKOPUS algorithm using the SPMF open-source data mining library.

How to run this example?

  • If you are using the graphical interface, (1) choose the "SKOPUS" algorithm, (2) select the input file "contextPrefixSpan.txt", (3) set the output file name (e.g. "output.txt") (4) set k = 5, use_leverage = true, max_pattern_length = 10, use_smoothed_values = true, smoothing_coefficient = 0.5 and (5) click "Run algorithm".
  • If you want to execute this example from the command line, then execute this command:
    java -jar spmf.jar run SKOPUS contextPrefixSpan.txt output.txt 5 true 10 true 0.5 in a folder containing spmf.jar and the example input file contextPrefixSpan.txt.
  • If you are using the source code version of SPMF, launch the file "MainTestSKOPUS.java" in the package ca.pfv.SPMF.tests.

What is SKOPUS?

SKOPUS is an algorithm for discovering the top-k most frequent sequential patterns in a sequence database, using the leverage or support measures. SKOPUS was proposed by Petijean et al.(2015).

A difference between SKOPUS and other top-k sequential pattern mining algorithms offered in SPMF is that SKOPUS use statistical testing to try to find significant patterns.

What is the input of SKOPUS?

The input of SKOPUS is a sequence database and a few user-specified parameters:

  • k : a positive integer representing the desired number of patterns to be found
  • use_leverage: if this parameter is set to true, the leverage is used for selecting patterns. Otherwise, the support (occurrence frequency) is used.
  • max_pattern_length: integer indicating the maximum number of items per patterns that the algorithm will discover
  • use_smoothed_values: if true, the algorithm will use smoothed values (see the paper about SKOPUS for details).
  • smoothing_coefficient: this parameter (a double value) is optional and specify a smoothing coefficient to be used for smoothing.

A sequence database is a set of sequences where each sequence is a list of itemsets. An itemset is an unordered set of items. For example, the table shown below contains four sequences. The first sequence, named S1, contains 5 itemsets. It means that item 1 was followed by items 1 2 and 3 at the same time, which were followed by 1 and 3, followed by 4, and followed by 3 and 6. It is assumed that items in an itemset are sorted in lexicographical order. This database is provided in the file "contextPrefixSpan.txt" of the SPMF distribution. Note that it is assumed that no items appear twice in the same itemset and that items in an itemset are lexically ordered.

ID Sequences
S1 (1), (1 2 3), (1 3), (4), (3 6)
S2 (1 4), (3), (2 3), (1 5)
S3 (5 6), (1 2), (4 6), (3), (2)
S4 (5), (7), (1 6), (3), (2), (3)

What is the output of SKOPUS?

SKOPUS discovers the top-k most frequent sequential patterns that occurs in the input sequence database, where k is set by the user. Note that it is possible that SKOPUS could return more than k patterns if several patterns have exactly the same leverage or support.

To explain more formally what is a sequential pattern, it is necessary to review some definition.

A sequential pattern is a sequence. A sequence SA = X1, X2, ... Xk, where X1, X2... Xk are itemsets is said to occur in another sequence SB = Y1, Y2, ... Ym, where Y1, Y2... Ym are itemsets, if and only if there exists integers 1 <= i1 < i2... < ik <= m such that X1 ⊆ Yi1, X2 ⊆ Yi2, ... Xk ⊆ Yik.

The support of a sequential pattern is the number of sequences where the pattern occurs divided by the total number of sequences in the database.

Besides the support measure, SKOPUS can use another measure called leverage to select interesting sequential patterns. Please refer to the paper about SKOPUS to know how this measure is calculated.

Why using SKOPUS? It is often hard to set the minsup threshold of sequential pattern mining algorithm to get a fixed number of patterns without running the algorithms several times and fine-tuning the parameter. With a top-k sequential pattern mining algorithm, the user can set k the number of patterns to be output directly, which is more intuitive than using minsup. Besides, SKOPUS apply statistical testing to try to find patterns that are really significant.

For example, if we run SKOPUS with k=5, using the leverage measure and the other parameters specified in this example on the example sequence database, the top-5 most patterns are:

ID Sequential Pattern Support Leverage
S1 (5), (6),(3) 50% (2 sequences) 1.33
S2 (1), (2), (3) 100% (4 sequences) 1.33
S3 (1), (4),(3) 75% (3 sequences) 1.33
S4 (5),(1),(6),(3) 50% (2 sequences) 1.25
S5 (5)(1)(6)(3)(2) 50% (2 sequences 1.2

For instance, the sequential pattern "(5),(6),(3)" appears in the third and fourth sequence (it has therefore a support of 50%), and has a leverage of 1.33.

And if the support measure is used instead the leverage, the SKOPUS algorithm finds the following top-5 patterns:

ID Sequential Pattern Support
S1 (2),(3) 100 % (4 sequences)
S2 (1) (2) (3) 100 % (4 sequences )
S3 (1), (3) 100 % (4 sequences )
S4 (1), (4) 75 % (3 sequences)
S5 (1), (2) 100 % (4 sequences )

Input file format

The input file format is defined as follows. It is a text file where each line represents a sequence from a sequence database. Each item from a sequence is a postive integer and items from the same itemset within a sequence are separated by single space. Note that it is assumed that items within a same itemset are sorted according to a total order and that no item can appear twice in the same itemset. The value "-1" indicates the end of an itemset. The value "-2" indicates the end of a sequence (it appears at the end of each line). For example, the input file "contextPrefixSpan.txt" contains the following four lines (four sequences).

1 -1 1 2 3 -1 1 3 -1 4 -1 3 6 -1 -2
1 4 -1 3 -1 2 3 -1 1 5 -1 -2
5 6 -1 1 2 -1 4 6 -1 3 -1 2 -1 -2
5 -1 7 -1 1 6 -1 3 -1 2 -1 3 -1 -2

The first line represents a sequence where the itemset {1} is followed by the itemset {1, 2, 3}, followed by the itemset {1, 3}, followed by the itemset {4}, followed by the itemset {3, 6}. The next lines follow the same format.

Note that it is also possible to use a text file containing a text (several sentences) if the text file has the ".text" extension, as an alternative to the default input format. If the algorithm is applied on a text file from the graphical interface or command line interface, the text file will be automatically converted to the SPMF format, by dividing the text into sentences separated by ".", "?" and "!", where each word is considered as an item. Note that when a text file is used as input of a data mining algorithm, the performance will be slightly less than if the native SPMF file format is used because a conversion of the input file will be automatically performed before launching the algorithm and the result will also have to be converted. This cost however should be small.

Output file format

The output file format is defined as follows. It is a text file. Each line is a frequent sequential pattern. Each item from a sequential pattern is a postive integer and items from the same itemset within a sequence are separated by single spaces. The value "-1" indicates the end of an itemset. On each line, the sequential pattern is first indicated. Then, the keyword " #SUP: " appears followed by an integer indicating the support of the pattern as a number of sequences.Then, if the leverage measure is used, the keyword " #LEVERAGE: " appears followed by a double indicating the leverage of the pattern. For example, a few lines of an output file (different from the example above) is:

5 -1 6 -1 3 -1 #SUP: 2 #LEVERAGE: 1.3333333333333335
1 -1 2 -1 3 -1 #SUP: 4 #LEVERAGE: 1.3333333333333335
1 -1 4 -1 3 -1 #SUP: 3 #LEVERAGE: 1.3333333333333333
5 -1 1 -1 6 -1 3 -1 #SUP: 2 #LEVERAGE: 1.25
5 -1 1 -1 6 -1 3 -1 2 -1 #SUP: 2 #LEVERAGE: 1.2

The first line indicates that the frequent sequential pattern consisting of the itemset {5}, followed by the itemset {6}, followed by the itemset (3) has a support of 2 sequences and a leverage equal to 1.33. The next lines follow the same format.

If the leverage measure is not used, then the result is:

1 -1 2 -1 3 -1 #SUP: 4
1 -1 3 -1 #SUP: 4
1 -1 2 -1 #SUP: 4
2 -1 3 -1 #SUP: 4
1 -1 4 -1 #SUP: 3

Optional feature: giving names to items

Some users have requested the feature of given names to items instead of using numbers. This feature is offered in the user interface of SPMF and in the command line of SPMF. To use this feature, your file must include @CONVERTED_FROM_TEXT as first line and then several lines to define the names of items in your file. For example, consider the example database "contextPrefixSpan.txt". Here we have modified the file to give names to the items:

@CONVERTED_FROM_TEXT
@ITEM=1=apple
@ITEM=2=orange
@ITEM=3=tomato
@ITEM=4=milk
@ITEM=5=bread
@ITEM=6=noodle
@ITEM=7=rice
@ITEM=-1=|
1 -1 1 2 3 -1 1 3 -1 4 -1 3 6 -1 -2
1 4 -1 3 -1 2 3 -1 1 5 -1 -2
5 6 -1 1 2 -1 4 6 -1 3 -1 2 -1 -2
5 -1 7 -1 1 6 -1 3 -1 2 -1 3 -1 -2

In this file, the first line indicates, that it is a file where names are given to items. Then, the second line indicates that the item 1 is called "apple". The third line indicates that the item 2 is called "orange". The 9th line indicates that the symbol "-1" must be replaced by "|". Then the following lines define four sequences in the SPMF format.

Then, if we apply a sequential pattern mining algorithm using this file using the user interface of SPMF or the command line, the output file contains several patterns, having this format:

apple | orange | #SUP: 4 

Note that this feature could be also used from the source code of SPMF using the ResultConverter class. However, there is currently no example provided.

Performance

SKOPUS is the only top-k sequential pattern mining algorithm for mining patterns using the leverage. Thus its performance cannot be directly compared with other algorithms.

Where can I get more information about this algorithm?

The SKOPUS algorithm is described in this paper:

François Petitjean, Tao Li, Nikolaj Tatti, Geoffrey I. Webb: Skopus: Mining top-k sequential patterns under leverage. Data Min. Knowl. Discov. 30(5): 1086-1111 (2016)

Besides, you may read this survey of sequential pattern mining, which gives an overview of sequential pattern mining algorithms.
