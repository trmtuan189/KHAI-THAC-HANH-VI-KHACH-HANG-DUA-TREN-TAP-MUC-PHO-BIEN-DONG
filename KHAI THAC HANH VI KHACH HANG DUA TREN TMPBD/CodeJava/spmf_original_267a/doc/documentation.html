Documentation

This section provides examples of how to use the SPMF open-source data mining library to perform various data mining tasks. If you have any question or if you want to report a bug,you can check the FAQ, or contact me. You can also have a look at the various articles that I have referenced on the algorithms page of this website to learn more about each algorithm. Moreover, you can have a look at the page about videos and other resources related to SPMF, including a textbook in Thai language.
