View erasable itemsets with the Visual Pattern Viewer (SPMF documentation)

Erasable itemsets are a type of patterns that can be produced by different algorithms offered in SPMF.

This page explains how to visualize the erasable itemsets found by an algorithm using the Visual Pattern Viewer.

How to run this example?

If you want to run this example using the graphical user interface of SPMF, follow these steps.

1) First, select an erasable itemset mining algorithm offered in SPMF. Several algorithms are offered and are described in the documentation of SPMF.

2) Then, in the user interface of SPMF, after selecting an algorithm and setting its input file path, output file path, and parameters, click on the combo-box besides "Open output file using:", and select "Visualize_Erasable_itemsets" so that the discovered patterns will be opened with the visual pattern viewer.

3) Then click on "Run algorithm" to run the algorithm.

After the algorithm terminates, the discovered patterns will be displayed using the Visual Pattern Viewer:

The Visual Pattern Viewer interface is quite intuitive. It displays each pattern with its value for each evaluation measure using a colored bar.

The Visual Pattern Viewer offers several features such as:

  • Viewing patterns using different layouts (grid, horizontal and vertical layout).
  • Sorting patterns by size and measure values.
  • Searching and filtering using measure values
  • Displaying statistics about the number of patterns found.

Other ways of running the Visual Pattern Viewer

It is also possible to run the Visual Pattern Viewer as an algorithm from the GUI of SPMF..

In this case, in the user interface of SPMF, select "Visualize_Erasable_itemsets" as algorithm. Then, select a file containing erasable itemsets as input file. Then, click "run algorithm".

This will display the patterns from the file using the Visual Pattern Viewer.

Besides, it is also possible to call the Visual Pattern Viewer from the command line interface of SPMF. To open a file called patternsErasableItemsets.txt, this syntax can be used:

java -jar spmf.jar run Visualize_Erasable_itemsets patternsErasableItemsets.txt in a folder containing spmf.jar and the input file.

What is the input file format?

The algorithm takes as input a file containing erasable itemsets.

The file format is defined as follows. It is a text file, where each line represents an erasable itemset.

The first two lines are metadata indicating the type of patterns in this file and the source of the data. Then the following lines provide the list of patterns. On each line, the items of the itemset are first listed. Each item is represented by an integer and it is followed by a single space. After, all the items, the keyword "#LOSS:" appears, which is followed by an integer indicating the loss of the itemset. For example, here a sample output file containing 8 itemsets:

@FILETYPE="Erasable itemsets"
@SOURCE="SPMF SOFTWARE https://philippe-fournier-viger.com/spmf/"
3 #LOSS: 150
5 #LOSS: 70
6 #LOSS: 80
7 #LOSS: 50
5 6 #LOSS: 150
5 7 #LOSS: 100
6 7 #LOSS: 100
5 6 7 #LOSS: 150
