View on-shelf high utility itemsets with the Visual Pattern Viewer (SPMF documentation)

On-shelf high utility itemsets are a type of patterns that can be produced by different algorithms offered in SPMF.

This page explains how to visualize the on-shelf high utility itemsets found by an algorithm using the Visual Pattern Viewer.

How to run this example?

If you want to run this example using the graphical user interface of SPMF, follow these steps.

1) First, select a on-shelf high utility itemset mining algorithm offered in SPMF. Several algorithms are offered and are described in the documentation of SPMF.

2) Then, in the user interface of SPMF, after selecting an algorithm and setting its input file path, output file path, and parameters, click on the combo-box besides "Open output file using:", and select "Visualize_Onshelf_High_Utility_itemsets" so that the discovered patterns will be opened with the visual pattern viewer.

3) Then click on "Run algorithm" to run the algorithm.

After the algorithm terminates, the discovered patterns will be displayed using the Visual Pattern Viewer:

The Visual Pattern Viewer interface is quite intuitive. It displays each pattern with its value for each evaluation measure using a colored bar.

The Visual Pattern Viewer offers several features such as:

  • Viewing patterns using different layouts (grid, horizontal and vertical layout).
  • Sorting patterns by size and measure values.
  • Searching and filtering using measure values
  • Displaying statistics about the number of patterns found.

Other ways of running the Visual Pattern Viewer

It is also possible to run the Visual Pattern Viewer as an algorithm from the GUI of SPMF..

In this case, in the user interface of SPMF, select "Visualize_Onshelf_High_Utility_itemsets" as algorithm. Then, select a file containing on-shelf high utility itemsets as input file. Then, click "run algorithm".

This will display the patterns from the file using the Visual Pattern Viewer.

Besides, it is also possible to call the Visual Pattern Viewer from the command line interface of SPMF. To open a file called patternsOnShelfHUIs.txt, this syntax can be used:

java -jar spmf.jar run Visualize_Onshelf_High_Utility_itemsets patternsOnShelfHUIs.txt in a folder containing spmf.jar and the input file.

What is the input file format?

The algorithm takes as input a file containing on-shelf high utility itemsets.

The file format is defined as follows. It is a text file, where each line represents a on-shelf high utility itemset .

The first two lines are metadata indicating the type of patterns in this file and the source of the data. Then the following lines provide the list of patterns. On each line, the items of the itemset are first listed. Each item is represented by an integer, followed by a single space. After, all the items, the keyword " #UTIL: " appears and is followed by the utility of the itemset. Then, the keyword "#RUTIL:" appears followed by the relative utility of this itemset. For example, we show below an example pattern file:

@FILETYPE="On-shelf high-utility itemsets"
@SOURCE="SPMF SOFTWARE https://philippe-fournier-viger.com/spmf/"
7 2 5 #UTIL: 9 #RUTIL: 0.8181818181818182
7 2 5 3 #UTIL: 11 #RUTIL: 1.0
7 5 #UTIL: 16 #RUTIL: 1.0
7 5 3 #UTIL: 24 #RUTIL: 1.5
7 5 3 1 #UTIL: 7 #RUTIL: 1.4
7 3 #UTIL: 15 #RUTIL: 0.9375
4 2 5 #UTIL: 36 #RUTIL: 0.9
4 2 5 3 #UTIL: 40 #RUTIL: 1.0
4 2 3 #UTIL: 34 #RUTIL: 0.85

For example, the second line indicates that the itemset {2, 3, 5, 7} has a utility of 11 $ and a relative utility of 1. The other lines follows the same format.
